# تثبيت Qatra Pro على هاتف Android

## الطريقة السريعة

1. انسخ مجلد التطبيق إلى الهاتف، أو شغله من كمبيوتر على نفس الشبكة.
2. افتح `index.html` أو رابط السيرفر من متصفح Chrome.
3. من قائمة Chrome اضغط: **إضافة إلى الشاشة الرئيسية**.
4. سيظهر التطبيق باسم **Qatra Pro**.

## تشغيله من الكمبيوتر على نفس الشبكة

داخل مجلد التطبيق شغل:

```bash
python -m http.server 8000
```

ثم من الهاتف افتح عنوان الكمبيوتر مثل:

```text
http://192.168.1.5:8000
```

ثم أضفه إلى الشاشة الرئيسية.

## مهم

- لا تحذف بيانات المتصفح قبل أخذ نسخة احتياطية.
- بعد كل يوم عمل صدّر نسخة JSON.
- الأفضل حفظ نسخة في الهاتف ونسخة خارجية في واتساب/تليجرام/فلاش.
