# Qatra Pro Owner Console

تطبيق Android خاص بمالك نظام Qatra Pro لإصدار منح التجربة لمدة 30 يومًا وملفات التفعيل الدائمة `.qlicense` من طلبات العملاء التي تبدأ بـ `QLR1.`.

## ما الذي يفعله التطبيق؟

- ينشئ مفتاح توقيع EC من نوع `secp256r1` داخل Android Keystore عند أول تشغيل.
- يحمي الدخول برمز مالك من 6 إلى 12 رقمًا مع قفل تدريجي للمحاولات الخاطئة.
- يحلل طلب التفعيل ويعرض هوية المنشأة ورمز الجهاز ونوع التطبيق.
- يسمح باختيار التطبيقات المشمولة: الإدارة، الكاشف، المحصل، والصندوق.
- ينشئ ملف `QATRA_LICENSE_V1` موقّعًا بـ `SHA256withECDSA` ومتوافقًا مع منطق التحقق في تطبيقات Qatra Pro.
- ينشئ منحة `QATRA_TRIAL_GRANT_V1` موقعة ومرتبطة بالجهاز لمدة 30 يومًا بالضبط.
- يحتفظ بمنحة كل جهاز ويعيد الملف الأصلي بنفس تاريخ الانتهاء بدل منح تجربة جديدة بعد إعادة التثبيت.
- يحفظ ملف `.qlicense` باستخدام منتقي ملفات Android ويمكن مشاركته مباشرة عبر واتساب أو البريد.
- يتحقق من ملفات التفعيل الصادرة من نفس أداة المالك.

## خطوة الربط الإلزامية قبل الاستخدام التجاري

المفتاح الخاص لا يخرج من الهاتف. بعد تثبيت التطبيق لأول مرة:

1. افتح التطبيق وأنشئ رمز المالك.
2. اضغط **نسخ المفتاح العام**.
3. ضع القيمة في `LICENSE_PUBLIC_KEY_BASE64` داخل إعداد بناء تطبيقات Qatra Pro الأربعة.
4. أعد بناء ملفات APK المخصصة للعملاء.
5. لا تحذف تطبيق أداة المالك ولا بياناته، لأن حذفها يفقد مفتاح التوقيع ويمنع إصدار تراخيص جديدة بنفس المفتاح.

الرخص الصادرة من هذه الأداة لن تُقبل في نسخ العملاء القديمة التي تحتوي مفتاحًا عامًا مختلفًا.

## البناء

```bash
gradle :owner-console:assembleDebug
```

وسيظهر APK في:

```text
owner-console/build/outputs/apk/debug/
```

كما يبنيه GitHub Actions عبر workflow:

```text
.github/workflows/build-owner-console.yml
```

## الأمان

- لا يوجد مفتاح خاص داخل GitHub أو APK.
- المفتاح الخاص غير قابل للتصدير من Android Keystore.
- الشاشة محمية من لقطات الشاشة والتسجيل عبر `FLAG_SECURE`.
- التطبيق مخصص لهاتف المالك فقط، ولا ينبغي توزيعه على العملاء أو نشره في متجر عام.
