# القواعد المحاسبية في Qatra Pro

## 1) المشروع قائم وليس جديداً

لذلك لا تبدأ الحسابات من الصفر. لكل مشترك يتم إدخال:

- قراءة افتتاحية.
- متأخرات سابقة.
- رصيد مقدم سابق.

## 2) معادلة الاستهلاك

```text
الاستهلاك = القراءة الحالية - القراءة السابقة
```

## 3) معادلة الفاتورة

```text
قيمة الفاتورة = الاستهلاك × التعرفة
```

## 4) معادلة الرصيد

```text
الرصيد = المتأخرات السابقة - الرصيد المقدم السابق + الفواتير - المدفوعات
```

## 5) تفسير الرصيد

- رصيد موجب = رصيد متبقٍ على المشترك.
- رصيد سالب = رصيد مقدم لصالح المشترك.
- دفع جزئي = تبقى الفاتورة جزئية.
- دفع أكثر من الرصيد المتبقي عليه = يتحول الزائد إلى رصيد مقدم.

## 6) الفاقد

```text
الفاقد = استهلاك العداد الرئيسي - استهلاك كل عدادات المشتركين في نفس الشهر
```

يتم اعتماد قراءة العداد الرئيسي في دورة نهاية الشهر.

## 7) أساس المحاسبة العامة

تعتمد شاشة «المحاسبة العامة» القيد المزدوج؛ لذلك يجب أن يتساوى مجموع المدين مع مجموع الدائن في كل قيد وفي ميزان المراجعة. القيود التشغيلية تُشتق من بيانات SQLite ولا تُنسخ في جدول ثانٍ، وهذا يمنع تكرارها بعد إعادة الاستيراد أو المزامنة.

## 8) القيود الآلية

| العملية | الطرف المدين | الطرف الدائن |
|---|---|---|
| متأخرات افتتاحية | ذمم المشتركين | حقوق الملكية الافتتاحية |
| رصيد مقدم افتتاحي | حقوق الملكية الافتتاحية | دفعات مقدمة من المشتركين |
| فاتورة مياه | ذمم المشتركين أو الدفعات المقدمة | إيرادات استهلاك المياه |
| تحصيل فاتورة | الصندوق أو البنك أو عهد المحصل | ذمم المشتركين |
| تحصيل زائد | الصندوق أو البنك | دفعات مقدمة من المشتركين |
| رسوم إدخال خدمة | الصندوق أو البنك | إيرادات إدخال الخدمة |
| مصروف | حساب المصروف المختص | الصندوق أو البنك أو الموردون |
| استلام من محصل | الصندوق | عهد وتحصيلات لدى المحصلين |
| إيداع بنكي | البنك | الصندوق |

لا يُثبت التحصيل كإيراد مياه مرة ثانية؛ الإيراد يُثبت عند إصدار الفاتورة، والتحصيل يسدد الذمة. كما يمنع النظام تكرار مصروف الصندوق المستورد عندما يكون قد أُضيف إلى سجل المصروفات.

## 9) دليل الحسابات والتقارير

يتضمن النظام دليلاً أساسياً للأصول والالتزامات وحقوق الملكية والإيرادات والمصروفات، ويمكن للإدارة إضافة حسابات فرعية رقمية دون حذف الحسابات النظامية. التقارير المترابطة هي:

- دفتر اليومية.
- الأستاذ العام مع رصيد افتتاحي للفترة.
- ميزان المراجعة.
- قائمة الدخل.
- قائمة المركز المالي.
- التدفقات النقدية المباشرة.
- أعمار ذمم المشتركين: 0–30، 31–60، 61–90، وأكثر من 90 يوماً.
- تسوية البنك والصندوق.

## 10) القيود اليدوية والتصحيح

لا يقبل النظام قيداً يدوياً غير متوازن، ولا يسمح بحذف القيد المرحّل. يتم التصحيح بواسطة قيد عكسي مرتبط بالقيد الأصلي مع سبب وتاريخ موثقين.

## 11) إقفال الفترات

قبل إقفال الشهر ينفذ النظام فحص توازن كامل. بعد الإقفال يمنع إدخال فواتير أو تحصيلات أو مصروفات أو تعديل قراءات الدورة أو ترحيل قيود يدوية داخل الشهر. إعادة الفتح تتطلب سبباً موثقاً من الإدارة.

## 12) الدقة والتصدير

تُحسب القيود حتى منزلتين عشريتين مع منع فرق يزيد على 0.01. جميع التقارير المحاسبية قابلة للطباعة A4 والتصدير إلى Excel في تطبيق Android، وتحفظ تلقائياً داخل مجلد قطرة برو الخاص بدور الإدارة.
